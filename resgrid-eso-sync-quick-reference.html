Resgrid-ESO Sync Quick Reference

Staff Training Guide & System Operation Overview

What It Does

Automatic Integration: Connects Resgrid dispatch system to ESO reporting with zero manual intervention.

Key Functions

  • Detects new emergency calls instantly
  • Extracts complete call data (37 fields)
  • Generates ESO-compliant XML files
  • Uploads to ESO servers automatically
  • Logs everything to Google Sheets

System Status Indicators

Green: System operating normally

Yellow: Minor issue, system still functional

Red: System error, requires attention

Check System Health

Health URL: [deployment-url]/health

Monitor Operations

  • Google Sheets "Logs" tab for system events
  • Google Sheets "Call Data" tab for processed calls
  • Check "ESO Upload Status" column for success/failure

Data Flow Process

  1. Call Created in Resgrid dispatch
  2. System Detects call via live connection
  3. Data Extracted from Resgrid (units, times, address)
  4. XML Generated in ESO format
  5. File Uploaded to ESO servers
  6. Results Logged to Google Sheets
Processing Time: Complete cycle typically takes less than 2 seconds

Google Sheets Overview

Call Data Tab (37 Columns)

  • Call Received Time, Emergency Call ID
  • Priority, Description, Responding Units
  • Address components, GPS coordinates
  • Unit timing data (dispatch, arrival, cleared)
  • ESO Upload Status, Generated XML

Logs Tab

  • System startup and connection events
  • Call processing activities
  • Upload success/failure notifications
  • Error messages and warnings

Call Processing Details

What Gets Captured

  • Basic Info: Call ID, nature, priority, address
  • Units: All responding units with individual timings
  • Times: Dispatch, en route, arrival, patient contact
  • Location: Full address, GPS coordinates
  • Patient: Name, DOB, contact information
  • Closure: Call closed time, final unit status

XML File Structure

  • CadIncident root element
  • Complete incident details
  • Individual unit entries with times
  • Patient information
  • GPS coordinates and addresses

Common Scenarios

Normal Operation

  • Call appears in Resgrid → Automatically processed → Shows in Google Sheets
  • ESO Upload Status shows "Successful"
  • XML column contains complete call data

Call Modifications

  • Unit assignments change → New XML generated
  • Address updated → GPS coordinates refreshed
  • Call closed → Final XML with closure data

Test Calls

  • Use "Test Call" button in Google Sheets
  • Creates test entry with "[TEST BUTTON]" identifier
  • Does not affect production data

Troubleshooting

If Calls Not Processing

  1. Check system health endpoint
  2. Verify Resgrid connection in logs
  3. Confirm API credentials valid
  4. Check Google Sheets for error messages

Upload Failures

  • ESO Upload Status shows "Failed"
  • Check SFTP credentials
  • Verify network connectivity
  • System will automatically retry
Support: Check Google Sheets Logs tab for detailed error messages and system status
