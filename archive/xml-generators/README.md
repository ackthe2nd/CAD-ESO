# Archived XML Generator Variants

This directory contains previous versions of the XML generator that are no longer in active use.

## Active Version
- `src/xml-generator.js` - Current production version with Pacific Time support and geocoding

## Archived Versions
- `xml-generator-updated.js` - Early template string implementation
- `xml-generator-exact-match.js` - Exact field mapping experiment
- `xml-generator-pacific-time.js` - Pacific Time conversion prototype

These files are retained for reference but should not be used in production.
