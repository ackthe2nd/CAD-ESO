How It Works

Automatic Operation: The system runs continuously in the background, requiring no manual intervention for day-to-day operations.

1. Call Detection & Processing

The system maintains a live connection to Resgrid's SignalR hub, instantly detecting new emergency calls. When a call is created or modified, the system immediately fetches complete call data including unit assignments, timing information, and incident details.

2. Data Transformation & Validation

Raw Resgrid data is transformed into ESO-compliant XML format with comprehensive field mapping. The system validates all data, applies GPS geocoding for addresses without coordinates, and ensures proper Pacific Time formatting.

3. Secure Upload & Verification

Generated XML files are securely uploaded to ESO servers via SFTP using enhanced connection strategies. The system verifies successful uploads and maintains XML integrity monitoring.

4. Complete Audit Trail

Every operation is logged to Google Sheets with Pacific Time standardization, providing complete operational visibility and compliance documentation.
